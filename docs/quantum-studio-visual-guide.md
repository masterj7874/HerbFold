# 양자 스튜디오 — 그림으로 읽는 계산 과정

실행 주소: **http://127.0.0.1:8873/#quantum**. 이전 화면이 열려 있다면 새로고침한다. 처음 방문하면 저장된 양자 실행을 보여 주며, 이미 선택해 둔 분석별/실행별 보기 설정은 유지한다.

## 사용 순서

1. **양자 실행** 목록에서 확인할 기록을 고른다. 입력 분자와 실행 ID는 선택한 기록에 연결된다. 원본 분석과 별도로 계산한 작업은 각각 자신의 그림·수치를 갖는다.
2. **분자 입력**에서는 선택 분자의 저장된 SMILES를 RDKit으로 그린 구조와 회로에 전달한 특징을 본다. **각도 인코딩**은 저장된 규칙에 따른 각도와 특징 반복을 보여 준다.
3. **양자 회로**에서는 전체 독립 블록 중 하나를 고른다. 해당 논리·물리 큐빗, H/Ry/Rz/CZ 게이트, 회전 각도와 측정 기저가 확대된다. 여러 층의 기록은 층을 선택할 수 있으며 생략된 후속 층을 표시한다. **회로 SVG**로 선택한 그림과 입력·출처 메타데이터를 저장한다.
4. **반복 측정**에서 입력 분자와 큐빗을 바꾼다. 기대값 구체를 드래그하거나 방향키로 회전하고, +/− 버튼으로 확대·축소한다. 0/Home 또는 초기화 버튼으로 돌아간다. 옆의 X/Y/Z 막대와 기록된 Wilson 구간을 함께 확인한다.
5. **유사도 비교**에서 관측 특징 기반 커널, 이상적 회로 계산, 고전 기술자 커널을 비교한다. 첫 행렬의 셀을 누르면 해당 분자 쌍의 값을 표시한다. 별도 반복 측정 값과 대각선 정의값을 구분한다.

**설명 재생**은 그림을 읽는 순서를 진행시키는 기능이다. IBM 실행 버튼과 별개이며 작업 제출·재제출을 하지 않는다. 일시정지가 가능하고, 화면이 보이지 않거나 탭이 숨겨지면 설명 타이머가 멈춘다. 운영체제의 동작 줄이기 설정에서는 자동 재생을 끄고 수동 탐색을 제공한다. 단계 탭은 방향키/Home/End로도 조작한다.

원시 표·대조·구간·실행 출처는 기존 상세 결과에 보존했다. 입력 분자·특징 행렬·SHA-256은 **입력 분자·특징 행렬·출처 자세히 보기**를 펼쳐 확인한다. 설명 단계의 1/5…5/5 표시는 하드웨어 작업 진행률이 아니다. 실제 실행 상태와 어느 단계의 자료가 있는지는 별도 펼침 영역에서 확인한다.

IBM 측정과 로컬 이상적 계산은 출처에 맞춰 설명한다. 로컬 관측량 기록에는 ‘계산한 기대값’을 표시하며, 측정 횟수로 얻은 값처럼 설명하지 않는다.

## 그림이 나타내는 실제 계산

| 단계 | 데이터와 계산 | 표시의 한계 |
|---|---|---|
| 입력 | 선택 작업의 payload.features 또는 일치하는 feature_definition.features; sample_ids/labels로 구조 연결 | 정의가 없으면 특징 이름·단위를 추정하지 않음. 구조가 없으면 임의 분자를 그리지 않음 |
| 각도 | 저장된 atan_fold_or_repeat_v1: 각 특징을 2 atan(x)로 변환. d < Q이면 반복, d ≥ Q이면 변환 후 strided 평균 | 지원되는 인코딩 정의·입력·큐빗 수가 없으면 실제 각도 미표시 |
| 회로 | independent_blocks_ry_rz_cz_v1의 저장된 blocks/edges 및 physical_qubits. 블록 내부 순서와 층 번호에 맞춘 회전 | 논리 회로 설명도이며 하드웨어 펄스 시간이나 순간 파동함수는 아님. 저장되지 않은 연결을 만들지 않음 |
| 관측 | projected_features의 명시적 axes 순서와 원시 값/구간 | 단위 구는 참고 좌표계. norm > 1 원시 추정값을 정규화하지 않으며 별도 설명. 전체 얽힌 상태나 원자 궤도가 아님 |
| 커널 | 실제 kernel, ideal_reference.kernel, classical_reference.kernel, controls.duplicate | RBF 대각선 1과 반복 측정은 다름. 특징 유사도는 결합 친화도·약효가 아님 |

전역 Fidelity 기록은 별도의 역회로→all-zero 반환 흐름과 실제 횟수/shot 분모를 보여 준다. 관측 0, 결측, 대기·실패를 구분하며 대기 기록에 영 행렬을 채우지 않는다. 블록·각도·기대값이 없는 기록에 다른 실행의 그래픽을 재사용하지 않는다.

## 참고한 시각 구성

[Vakili et al., “Quantum-computing-enhanced algorithm unveils potential KRAS inhibitors”, Nature Biotechnology (2025)](https://doi.org/10.1038/s41587-024-02526-3)의 Fig. 1, Extended Data Figs. 3 및 5에서 단계별 흐름, 전체→확대 구성, 색으로 구분한 게이트 표현을 참고했다. 원본 그림을 UI에 복사하지 않고 프로그램의 저장 자료와 회로 정의로 SVG를 새로 그렸다. 논문의 QCBM–LSTM 생성 모델과 이 앱의 descriptor-kernel 계산은 서로 다르다.

[Motion](https://motion.dev/docs/react-animation)의 React/SVG 전환을 사용한다. 운영체제의 동작 줄이기 설정은 `matchMedia` 변경 구독으로 새로고침 없이 반영하며, 설정을 켜면 진행 중인 설명 재생도 멈춘다. 도표는 DOM/SVG로 구현해 논리 회로가 픽셀 이미지 확대 때문에 흐려지지 않도록 했다. 추가 양자 서비스나 신규 애니메이션 패키지 설치는 필요하지 않다.

## 재검증

```bash
cd frontend
npm run build
node --test tests/*.test.mjs
```

프로젝트 루트에서 로컬 서버가 실행 중일 때:

```bash
python scripts/verify_quantum_journey_ui.py
```

검사 스크립트는 실제 저장된 두 관측량 실행과 하나의 전역 기록을 사용한다. 대기·지원되지 않는 버전·일부 누락 필드 사례는 브라우저 응답에만 주입한 테스트 자료로 분리한다. 하드웨어/LLM 작업 POST는 차단하며, 2차원 구조 표시용 로컬 RDKit 요청만 허용한다. 실행 결과와 화면은 tmp/quantum-studio-v3/에 기록한다. 새 약효 분석이나 QPU 측정을 수행하는 검사가 아니다.

최종 검증에서 프로덕션 빌드, 프론트엔드 단위 검사 22개, 브라우저 검사 항목 18개가 통과했다. 1440px·390px 화면을 열어 확인했으며, 저장 기록의 해시는 검사 전후 같았다. 로컬 출처 문구도 브라우저에만 주입한 별도 사례로 확인했다. [검증 결과·소스 및 화면 해시](quantum-studio-visual-verification.json).
