# 실제 분자 생성 성능 검증

2026-09-08에 로컬 원본 카탈로그로 **서로 다른 BRICS 절편 조합 5,000,000개를 실제 계산**했다. 구조 중복, 입력 부모 구조, 물성 필터 및 서로 다른 부모 구조 조건을 적용한 최종 저장 후보는 **3,701,740개**다. 원본 결과는 [scale-validation-results.json](scale-validation-results.json)에 기록했다. 이 수치는 계산 후보의 수이며 효능·안전성이 검증된 신약의 수가 아니다.

실행 호스트는 AMD Ryzen Threadripper 7980X, 64코어/128논리 CPU다. 생성 시간은 두 실행 구간의 실제 활성 경과 시간을 합친 값이며, 두 실행 사이의 대기와 사후 검증 시간을 포함하지 않는다. RSS는 커밋 시점에 부모·직접 자식 프로세스의 실제 RSS를 합산한 관측값으로, 공유 페이지가 중복 계산될 수 있다. 전체 기계 RAM 사용량 또는 엄밀한 최대 고유 메모리 측정은 아니다.

고유 후보 1,000,079개는 실제 시도 1,315,904개, 누적 생성 시간 85.560초 시점에 커밋되었다. 고유 후보 2,000,163개는 168.021초, 3,000,101개는 247.538초에 도달했다. 시간 측정 해상도는 최대 512개 시도를 처리하는 배치의 커밋 경계다. 3백만 시점의 원래 저장 수 3,000,103개 중 두 건은 아래의 사후 출처 검증으로 제외했다.

## 계산 방식과 유한한 탐색 공간

COCONUT·LOTUS 원본 카탈로그와 ChEMBL 승인 이력 자료의 구조를 사용했다. 준비된 부모는 천연물 역할 764,330개와 약물 역할 3,331개다. 동일 분자가 두 역할에 등장하는 경우를 포함한 767,661개 역할별 행이며, 서로 다른 카탈로그 분자 ID는 765,971개다. 두 역할에 등장하는 1,690개 분자를 독립적인 부모 두 개로 간주하지 않는다. 원본 카탈로그 최대 분자 ID와 출처 레코드 ID를 고정하여 이후 추가된 자료가 진행 중 탐색에 섞이지 않게 한다.

천연물 말단 BRICS 절편 117,422개, 약물 말단 절편 1,296개를 먼저 구조별로 중복 제거했다. 원본 부모의 절편 연결은 별도 `ancestry` 테이블에 저장한다. 각 조합에서는 RDKit BRICS 역반응으로 한 결합을 연결하고, 완전한 분자 구조와 물성을 실제 계산한다. 부모별 같은 절편 조합을 반복해 숫자를 늘리지 않는다.

현재 절편 집합의 BRICS 라벨 호환 조합 슬롯은 **85,150,669개**다. 이는 유효하거나 고유한 분자의 수를 보장하는 값이 아니다. 현재 한 결합 조합 방식에서는 **1억 개의 서로 다른 슬롯조차 존재하지 않으므로 1억 후보 생성이 검증되었다고 주장할 수 없다.** 실제 실행은 첫 500만 슬롯에서 종료했다.

슬롯은 BRICS 연결 라벨 그룹 순서이며, 각 그룹의 절편은 SMILES SHA-256 순서로 정렬한다. 후속 그룹은 구조 크기·필터 통과율·처리 시간이 다를 수 있다. JSON의 시간 외삽은 첫 구간을 기준으로 한 계산값이고, 실제 1억 건 실행 결과 또는 지속 처리량 보증이 아니다.

## 구조·출처 검증 범위

모든 저장 행은 전체 canonical isomeric SMILES와 SHA-256 키로 중복을 제한한다. 사후 SQL 검사에서 최종 3,701,740개 행의 물성 조건 위반과 서로 다른 부모 구조 조건 위반은 각각 0개였다. 서로 다른 부모 조건은 출처 이름이나 카탈로그 ID가 아니라 표준화한 부모 SMILES로 확인했다. 양쪽 절편의 부모 집합이 각각 동일한 단일 구조만 포함하면 탈락시킨다.

초기 시간 측정에서는 3,701,743개를 저장했으나 전체 출처 검증에서 위 조건을 위반한 3개를 발견하여 제외했다. 원래 측정 영수증은 `runtime/validation/scale/scale-attempts-5000000-before-lineage-audit.json`에 보존했다. 수정 후 생성 시간을 다시 측정한 것처럼 바꾸지 않았다. 생성기에도 동일한 출처 조건과 회귀 테스트를 추가했다.

고정된 구조 해시 표본 500개를 다시 계산하여 저장된 canonical 구조·해시와 일치함을 확인했고, 해당 표본의 서로 다른 868개 절편을 원본 부모로부터 다시 분해하여 출처를 확인했다. 두 표본 검사 모두 실패 0개였다. 이는 모든 후보에 대한 독립 재계산이나 생물학적 검증을 뜻하지 않는다.

최종 정렬 구조 해시:

```text
b8641601549726781902371990e680fb8b0b7c6220aeae4af54627bde8eb4fbf
```

QED 및 분자량·logP·TPSA 제한은 계산 선별 조건이다. 효능, 독성, 결합 친화도, 합성 가능성, 특허 신규성은 이 벤치마크에서 검증하지 않는다. 후속 모델 평가나 실험은 별도 범위와 표본 수를 명시해야 한다.

## 재현과 저장

```bash
.venv/bin/python scripts/benchmark_discovery_scale.py \
  --workers 16 --attempts 5000000 --max-seconds 1800
```

기본 결과 위치는 `runtime/validation/scale`이다. 별도의 `--root`를 지정하면 독립적인 실행을 시작한다. 동일 디렉터리에서는 SQLite 커서와 함께 커밋된 후보에서 재개하며, 파일 잠금으로 두 작업자가 동시에 같은 탐색을 진행하지 못하게 한다. 프로세스 중단은 미커밋 배치를 되돌린다. 목표 시도 수·실행 시간·저장량·디스크 여유 예산을 적용하며, 실제 과학 연산 중 LLM·AlphaFold·QPU 서비스는 호출하지 않는다.

관련 테스트는 `tests/test_scale_validation.py`에 있다. 실제 화학 연산, 중단 후 재개, 목표 초과 방지, 체크포인트 롤백, 중복 제거, 원본 스냅샷, 서로 다른 염/출처 ID가 같은 부모 구조인 경우, 읽기 전용 감사 및 동시 실행 차단을 확인한다.
